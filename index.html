สวัสดีค่ะ ดิฉันชื่อนางสาว ณัฎฐณิชา ลังกาเปี้ย

นักศึกษาวิศวกรรมไฟฟ้า | ผู้เริ่มต้นเขียนเว็บไซต์เพื่อนำไปต่อยอดกับเกมที่กำลังพัฒนาของตนเอง

ดิฉันกำลังศึกษาอยู่ชั้นปีที่ 4 สาขาวิศวกรรมไฟฟ้า มีความตาวาวสนใจ การพัฒนาเว็บไซต์และการออกแบบ เป็นพิเศษ และกำลังมองหาโอกาสได้ร่วมแลกเปลี่ยนความคิดสำหรับการนำมาพัฒนา

ติดต่อดิฉัน

จุดเยือกแข็งบนยอดเขาเอเวอร์เรส

ยิ่งสูงยิ่งหนาว

  • ออกแบบได้หากต้องการ
  • ทำงานอย่างตั้งใจและพร้อมปรับปรุงแก้ไข
  • แม้มีปัญหาเข้ามาก็พร้อมทำงานจนสำเร็จลุล่วง

ความมืดบอดในใจของดิฉัน

  • หวาดระแวงและประหม่าเมื่ออยู่กับผู้คนเป็นเรื่องจากอดีตที่ส่งผล ปัจจุบันกำลังปรับปรุงแก้ไขในเรื่องของการเข้าสังคมอยู่เสมอ
  • ภาวะเครียด วิตกกังวล และกดดันตนเองเป็นผลมาจากการสะสม ปัจจุบันจึงอยู่กับตนเองมากขึ้นและใช้ศิลปะบำบัดผ่อนคลาย

ทักษะน่าสนใจ

HTML

วางโครงสร้างหน้าเว็บด้วยแท็กเชิงความหมาย ได้รับจากอาจารย์ผู้มีประสบการณ์

CSS

จัดเลย์เอาต์ด้วย Flexbox และ Grid ด้รับจากอาจารย์ผู้มีประสบการณ์

JavaScript

เขียนการโต้ตอบพื้นฐานบนหน้าเว็บ ด้รับจากอาจารย์ผู้มีประสบการณ์

Python

เขียนสคริปต์คำนวณและวิเคราะห์ข้อมูล ด้รับจากอาจารย์ผู้มีประสบการณ์
